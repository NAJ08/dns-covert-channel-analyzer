What is DNS & How Does Resolution Work?

Hierarchical Inverted Tree Structure
Protocol Foundations

The Domain Name System (DNS) serves as the internet's decentralized hierarchical directory, translating human-memorized Fully Qualified Domain Names (FQDNs like telemetry.lab.net) into numerical 32-bit IPv4 or 128-bit IPv6 hardware routing addresses.

A single client resolution request triggers an iterative chain across globally distributed server roles. Unless cached locally, the resolver traverses the root zone (.), the Top-Level Domain (.com / .net), and eventually queries the domain's dedicated authoritative server.

DNS Steganography

Covert Encoding

DNS Steganography is the practice of embedding arbitrary hidden payloads directly into RFC-standard DNS protocol fields without corrupting the operational syntax of the request or response.

Covert Storage Channels

Security Policy Breach

Originally formulated by Butler Lampson (1973), a covert channel is any communication path that transfers signals between systems in a manner violating access control rules, using standard protocols never conceived for data transport.

public Overt Channel (Legit)
  • • Standard DNS protocol intent
  • • Small canonical payloads (< 64B)
  • • Expected distribution of dictionary words
  • • Transparent inspection across proxies
visibility_off Covert Channel (Tunnel)
  • • Subverts perimeter policy via UDP/53
  • • High query volume & long label sequences
  • • Encrypted entropy matching random noise
  • • Undetected exfiltration past DLP

DNS Packet Structure (RFC 1035 Wire Format)

Hex / Wire Breakdown

A raw RFC 1035 DNS datagram is split into exactly 5 logical segments over wire. The 12-byte fixed header is followed by 4 variable-length descriptor sections containing query labels and Resource Records (RRs):

1. Header 12 Bytes

Fixed structure. Contains Query ID, Opcode, Flags (QR, AA, TC, RD, RA, RCODE), and record section counters.

ID, Flags, QDCOUNT
2. Question Variable

Specifies target domain labels in length-octet format, followed by Query Type (A, TXT, CNAME) and Class (IN).

QNAME, QTYPE, QCLASS
3. Answer Variable

Resource records satisfying the query (e.g., IPv4 octets in type A, or raw string data in TXT records).

NAME, TYPE, TTL, RDATA
4. Authority Variable

Nameservers holding authoritative authority for the requested namespace (SOA or NS pointer records).

NS Records (NSCOUNT)
5. Additional Variable

Holds resolver glue records and RFC 6891 EDNS0 pseudo-records (often exploited for payload stuffing).

OPT, EDNS0, Glue IP

Shannon Information Entropy

H(X) Metric

Formulated by Claude Shannon (1948), Information Entropy quantifies the expected unpredictability, surprise, or randomness contained within a signal's discrete probability distribution.

Shannon Formulation
H(X) = - ∑i=1n P(xi) × log2 P(xi)
Where P(xi) is the frequency ratio of each byte character across the domain label.
